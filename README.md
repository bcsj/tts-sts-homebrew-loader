# Tabletop Simulator Slay the Spire Homebrew Character Loader

This is a Tabletop Simulator mod implementing a tool for patching homebrew characters into the Slay the Spire boardgame mod.

The mod is available on the Steam Workshop

- https://steamcommunity.com/sharedfiles/filedetails/?id=2915609958
